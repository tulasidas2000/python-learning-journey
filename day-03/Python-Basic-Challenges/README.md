## ▶️ Running the Programs

Make sure **Python 3** is installed.

Clone the repository:

```bash
git clone <your-repository-url>
```

Open the project folder and run any program:

```bash
python odd_or_even.py
```

For example:

Enter a number: 8
8 is an Even Number
```
