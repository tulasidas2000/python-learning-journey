# Python Beginner Projects: Tip Calculator & BMI Calculator
This folder contains two beginner-friendly Python programs built while practicing Python fundamentals, user input, and basic calculations.
## Projects
### 1. Tip Calculator
The Tip Calculator calculates:
- Tip amount
- Total bill
- Amount each person should pay when splitting the bill
It accepts the bill amount, tip percentage, and number of people as user input.
### 2. BMI Calculator
The BMI Calculator calculates a person's Body Mass Index (BMI) using their height and weight.
It demonstrates how Python can process user input and perform mathematical calculations.
## Concepts Practiced
- Strings
- Integers and floats
- User input with `input()`
- Type conversion using `int()` and `float()`
- Arithmetic operations
- Storing values in variables
- Displaying calculated results
## How to Run
Make sure Python is installed, then run the programs from the terminal:
```bash
python Tip Calculator.py
python BMI Calculator.py
