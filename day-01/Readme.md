## Band Name Generator

A simple Python script that generates a band name by combining user inputs — 
built while practicing Python fundamentals, specifically variable naming.

## What I practiced
- Writing readable variable names using underscores to separate words (`city_name`, not `cityname` or `city name`)
- Avoiding spaces and leading digits in variable names (invalid in Python)
- Avoiding reserved keywords (like `print` or `input`) as variable names, since 
  Python throws errors when built-in functions get overwritten

## How to run
```bash
python band_name_generator.py
```

## What it does
Takes user input (e.g. a city name and a pet's name) and combines them to 
generate a band name suggestion.
